## 🎯 ¿Qué es AI Builder Academy?
AI Builder Academy es una plataforma enfocada en la creación práctica de productos basados en Inteligencia Artificial. En lugar de contenido teórico pasivo, guía al usuario paso a paso con un mentor de IA interactivo según su nivel de experiencia y objetivos de construcción.

### ✨ Características Principales
- 💡 **Selector de Ideas y Proyectos:** Generador de ideas rápidas (agentes de atención al cliente, asistentes de estudio, SaaS de IA, etc.).
- 🎯 **Ruta Personalizada por Nivel:** Adaptado para perfiles Principiante, Intermedio y Avanzado.
- 🌐 **Soporte Multi-idioma:** Interfaz disponible en Español (ES) e Inglés (EN).
- ⚡ **Diseño Ultra Rápido:** Construido con Vite, React y Tailwind CSS con tipografías optimizadas (*Manrope* y *Sora*).

## 🛠️ Stack Tecnológico
- **Frontend:** React + TypeScript
- **Estilos & Diseño:** Tailwind CSS + Tokens de diseño personalizados
- **Empaquetador & Servidor:** Vite
- **Desarrollo Rápido:** Lovable

## 🚀 Instalación y Ejecución Local

1. **Clonar el repositorio:**
   \`\`\`bash
   git clone https://github.com/estjuanmartinez6-jpg/pixel-perfect-showcase-8713.git
   cd pixel-perfect-showcase-8713
   \`\`\`

2. **Instalar dependencias:**
   \`\`\`bash
   npm install
   \`\`\`

3. **Ejecutar en modo de desarrollo:**
   \`\`\`bash
   npm run dev
   \`\`\`

4. **Compilar para producción:**
   \`\`\`bash
   npm run build
   \`\`\`
